# Cortex DataHub client postman collection

This project contains a single file application that demonstrates how to connect and use the API with postman.

It is intended to be used by the external clients as running sample.

The purpose of this collection is to be copied onto the DevPortal, in the documentation section of the API.

It does not depend on the rest of the project, it is totally independent.


#### Requirements

Import the json file in your Postman collections.
